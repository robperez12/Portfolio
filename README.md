# Rob Perez | Professional Portfolio

A responsive, single-page portfolio for GitHub Pages. Emerald, copper, and editorial typography reflect Rob's leadership experience and Executive Change Brief identity.

## Preview
Open index.html in your browser. No installation is required.

## Publish in your Portfolio repository
1. Extract this ZIP on your computer.
2. In GitHub, open robperez12/Portfolio.
3. Choose Add file > Upload files.
4. Upload index.html and this README.md to the repository root. Commit changes.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select main and /(root), then Save.
8. When GitHub finishes publishing, your expected address is https://robperez12.github.io/Portfolio/.

If README.md already exists, edit it directly or upload only index.html.
